# 04 — UI (53 screens, UMG + CommonUI)

Style: parchment panels, brass frames, wax-seal buttons, rope dividers,
ink stamps; serif headings + clean body. Colours: parchment, dark ink,
brass gold, sea teal (focus), blood red (danger). Icons from real models.
Previews use world camera. KB/mouse + gamepad + touch day one.
Per screen: wireframe → approval → mockup → build → device test.

A. Front: Loading, Title, Main menu, Mode select, Ship select, Crew setup,
Setting sail, Pirate Generator, Tutorial hints.
B. HUD: reticle, health (on damage), oxygen ring, ammo pips, interact prompt +
hold ring, item hints, banner, toasts, nameplates, screen states (damage/low/
drunk/wet/underwater/spyglass/death), item/map/emote/phrase wheels,
barrel inventory, voyage/banner/map tables, vote cards, touch layouts.
C. Shops: template (rail, grid, detail live try-on, gold, filters, lock reasons,
hold-to-buy) → Tailor, Weaponsmith, Outfitter, Shipwright, Faction, Premium
(later), chests, outfit slots, NPC dialogue, sell flow.
D. Pirate Log book: stats, reputation, commendations, titles, renown (later),
ships (later), journal, leaderboard.
E. System: Pause, My Crew, Settings (controls/gameplay/audio/video/access/
HUD/lang), rewards, deeds board, dialogs.
