# 02 — World

## Grid
8x8 lettered grid, ~8x8km, World Partition, streamed. Border storm wall
"the Shroud" (kill volume + VFX). Build Sunlit Shallows slice first,
other regions grey-box.
Regions: Sunlit Shallows (starter), Verdant Reach, Ashen Narrows, Ember Deeps.
Types: outpost, sea post, large island, small island, skeleton fort,
shipwreck, skeleton camp, reefs.

## Gullrest Outpost
Docks: slips, resource barrels, ship customisation chest, crew board.
Shipwright: hull/sail/figurehead swatches, model sloop, preview on real ship.
Tavern (spawn): bar+barkeep, tables, fireplace, shanty stage, deeds board,
bunk room (clothing/vanity chests), locked Legend door.
Tailor: mannequins, hat shelves, boot rack, cloth rolls, mirror, fitting
podium (stand → camera to pirate → live try-on shop).
Weaponsmith: forge, anvil, racks, armoury chest, shooting range.
Outfitter: tool shelves, inspect table, equipment chest.
Factions (rep + sell + banner): Gilded Ledger (chests), Lantern Wardens
(skulls/bounties), Tradewind Guild (cargo/animals), Saltline Anglers (fish).
Wayfinding: hanging signs + lit windows. No map markers.
Later: premium stall, Black Tide hideout (PvP), legend hideout.

## Island recipe
1 landmark readable from sea, 2 landing beaches, 2-3 named riddle features,
dig zones, cave/secret, enemy zones, wildlife, loose barrels.
Top-down render → parchment map art.

## Sky/weather
24-min day, painted sunsets, north star, storm cell (rain, big waves,
lightning, spinning compass, wheel pull), fog banks, cloud signals over events.
