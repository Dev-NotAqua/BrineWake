# 00 — Pillars, Journey, Generator

## Pillars
1. Tools, not menus: compass, map, lantern, watch are held objects. HUD near zero.
2. A ship needs hands: every station is a physical job (wheel, sails, capstan, cannons).
3. Cosmetic-only progression: gold buys looks, never power.
4. Chunky painted world: simplified forms, hand-painted textures, visible wear.
5. Nothing ships silent: feature done only with SFX + VFX + UI feedback.

## Player journey
Title → (first time: Pirate Generator → tutorial "First Tide") → mode →
ship size → crew → spawn in tavern → stock up → voyage at ship table →
sail → island objective → carry loot home → sell → gold + rep →
shops → repeat.

## Pirate Generator (dockside stage, 8 pirates in ring)
Rotate, Inspect, Favourite (survives rerolls), Reroll, hold Confirm.
Seeded: 4 builds (lean, stocky, burly, round) + proportions; 6 heads;
stacked face layers (eyes/nose/mouth/brows); 12 skin tones;
12 hairstyles x 10 colours; 8 beards; scars, freckles, asymmetry; voice pitch.
Unreal: UE mannequin base + SkeletalMeshMerge parts. Clothes = mesh swaps +
rigid accessories. Appearance locked; "Sea-Change Tonic" at tailor reopens.
Display name shown, not platform avatar.
