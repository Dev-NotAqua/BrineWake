\subsection{Base first-person character (\texttt{ABrinewake2Character})}
Source: \texttt{Source/Brinewake2/Brinewake2Character.cpp}, constructor.

\begin{itemize}[leftmargin=1.4em]
  \item Capsule: initialised $55 \times 96$ then set to \textbf{radius $34.0$\,cm, half-height $96.0$\,cm} via \texttt{SetCapsuleSize(34.0f, 96.0f)}.
  \item First-person mesh: owner-only (\texttt{SetOnlyOwnerSee(true)}, profile \texttt{NoCollision}); third-person mesh set to \texttt{OwnerNoSee} world-space representation.
  \item Camera: attached to head socket at $(-2.8,\,5.89,\,0.0)$\,cm, $70^\circ$ FOV, first-person scale $0.6$.
  \item Movement: \texttt{BrakingDecelerationFalling = 1500.0}~cm/s$^2$, \texttt{AirControl = 0.5}. All other \texttt{UCharacterMovementComponent} values are engine defaults (gravity scale $1.0$, world gravity $-980$\,cm/s$^2$ unless overridden in a map).
  \item Input: Enhanced Input only; move/look/jump routed through \texttt{DoMove/DoAim/DoJumpStart/DoJumpEnd}.
\end{itemize}

Hit pipeline (\texttt{NotifyHit}): first hit wins (\texttt{bHit} guard) $\rightarrow$ disable collision $\rightarrow$ \texttt{MakeNoise} $\rightarrow$ direct \texttt{ProcessHit} \emph{or} \texttt{ExplosionCheck} (sphere overlap vs.\ \texttt{Pawn}, \texttt{WorldDynamic}, \texttt{PhysicsBody}, each actor damaged once) $\rightarrow$ Blueprint event \texttt{BP\_OnProjectileHit} $\rightarrow$ destroy now or after $5$\,s.

Damage + impulse rule (\texttt{ProcessHit}):
\begin{equation}
\text{if target is } \mathtt{ACharacter} \Rightarrow \mathtt{ApplyDamage}(25), \qquad
\text{if } \mathtt{HitComp.IsSimulatingPhysics()} \Rightarrow \mathbf{J} = \hat{\mathbf{d}}\cdot 100 \text{ at impact point}.
\end{equation}

\subsection{Kinematic model (for tuning docs)}
With no drag/gravity configured on \texttt{ProjectileMovement}, flight is rectilinear at $v_0 = 3000$\,cm/s:
\begin{equation}
\mathbf{x}(t) = \mathbf{x}_0 + \mathbf{v}_0 t, \qquad t_{\text{hit}} \approx \frac{d}{3000~\text{cm/s}}.
\end{equation}
At $30$\,m the flight time is $\approx 1.0$\,s; at the NPC aim range $100$\,m it is $\approx 3.3$\,s.
If gravity is later enabled on the movement component with scale $g_s$, use
\begin{equation}
\mathbf{x}(t) = \mathbf{x}_0 + \mathbf{v}_0 t + \tfrac{1}{2}\, g_s(-980\,\hat{\mathbf{z}})\,t^2,
\end{equation}
so drop at $50$\,m ($\approx 1.67$\,s) would be $\approx 1.37\,g_s$\,m --- keep $g_s = 0$ for hitscan-feel flintlocks, $g_s > 0$ for cannonballs (ship combat).

\section{Collision, damage and death}
\label{sec:collision}

\begin{enumerate}[leftmargin=1.4em]
  \item \textbf{Direct hit:} $25$~HP damage. A $100$~HP NPC dies in $4$ torso hits (before falloff/headshot multipliers, which are not yet in code).
  \item \textbf{Explosion (opt-in):} $5$\,m sphere overlap; damage + radial impulse per actor once. Owner excluded unless \texttt{bDamageOwner}.
  \item \textbf{Physics push:} $100$-unit impulse at impact point --- visible nudge on props, negligible on characters (by design; use knockback separately).
  \item \textbf{Ragdoll:} NPCs switch to \texttt{Ragdoll} profile on death, linger $5$\,s, then destroy. Player death flow (ghost ship $15$--$25$\,s, loot floats $5$\,min) is design-spec, not yet coded --- see \S\ref{sec:content}.
\end{enumerate}

\section{Ship, ocean and buoyancy (design + integration plan)}
\label{sec:ships}

From \texttt{Docs/01-Tech-Unreal.md} (spec; grey-box ship milestone M1 is the prove-out):

\begin{itemize}[leftmargin=1.4em]
  \item Ocean: Water plugin, custom Gerstner-wave material; wave parameters replicated from server with server time so all clients evaluate the same surface.
  \item Ship: \textbf{single server-authoritative Pawn}, Chaos physics + Buoyancy sample points on hull. Clients predict; acceptance criterion \texttt{p.netshowcorrections 1} stays clean with 2 clients in a storm.
  \item Deck walking: attach characters to ship; test jitter explicitly (listed project risk).
  \item Reference buoyancy model for the design doc:
\begin{equation}
\mathbf{F}_{\text{buoy}} = -\rho\, g\, V_{\text{sub}}\,\hat{\mathbf{z}} + \mathbf{F}_{\text{damp}}(\mathbf{v}, \boldsymbol{\omega}),
\end{equation}
  with one sample per hull pontoon in the Chaos Buoyancy component, $\rho = 1025$\,kg/m$^3$ seawater, $V_{\text{sub}}$ from Gerstner height field. Cannon recoil, hole flooding (3 hole sizes at fixed sockets), bailing and sinking are server-auth gameplay states layered over this force, \emph{not} rigid-body shattering.
  \item Netcode: listen-server, 1 ship / 4 players for M1, target 5 ships / 16 players by M9.
\end{itemize}

\section{Game content reference}
\label{sec:content}

\subsection{High concept (from \texttt{Docs/00,02,03})}
\textbf{Brinewake}: Sea-of-Thieves-like co-op pirate sandbox (original IP). Pillars: (1) tools, not menus (compass/map/lantern are held objects); (2) a ship needs hands (every station is a physical job); (3) cosmetic-only progression; (4) chunky painted look; (5) nothing ships silent (every feature needs SFX+VFX+UI).

World: $8\times8$ lettered grid ($\approx 8\times8$\,km), World Partition streaming, storm-wall border (``the Shroud'' kill volume). Regions: Sunlit Shallows (starter slice), Verdant Reach, Ashen Narrows, Ember Deeps. Hub: Gullrest Outpost (docks, shipwright, tavern spawn, tailor, weaponsmith, outfitter, four faction halls). Island recipe: 1 sea-readable landmark, 2 beaches, 2--3 riddle features, dig zones, cave/secret, enemy + wildlife zones.

\subsection{Gameplay systems}
On foot: walk/sprint/jump/swim/dive (oxygen), ladders, two-handed loot carry, sit/sleep/emotes; tools (compass, map, watch, lantern, spyglass, shovel, bucket, trumpet, rod, tankard, 4 instruments); arsenal cutlass/flintlock/scattergun/long-rifle (carry 2, 5 shots each per design --- code default magazine is 10, reconcile per weapon); cooking (raw $\rightarrow$ cooked $\rightarrow$ burnt).
Ships: wheel, sail length/angle, capstan, cannons, chart/voyage/banner tables, armoury, stove, bell, crow's nest; damage states (holes $\rightarrow$ flood $\rightarrow$ bail/plank $\rightarrow$ sink; fire/mast later).
Voyages: Ledger (X-marks/riddles), Wardens (skeleton captain), Tradewind (timed cargo/animals), Anglers (fish/cook/sell) + emergent bottles/wrecks/forts/shark; loot 5 tiers; trick chests; powder kegs; alliance banners grade 1--5 to $2.5\times$.
Economy/death/social: gold + rep $1$--$50$ + commendations; ghost-ship respawn $15$--$25$\,s, sunk ships respawn far with loot floating $5$\,min; Open Seas (PvP) vs.\ Calm Seas (private); crews $1$--$4$, proximity voice, brig vote.

\subsection{Modes shipped in this snapshot}
\texttt{FirstPerson} template base + \texttt{Variant\_Shooter} (AI StateTree shooter with pickups, spawner, bullet-counter UI) + \texttt{Variant\_Horror} (stamina sprint, spotlight, horror UI). Full pirate systems (ships, voyages, vendors, shanties) are spec'd in \texttt{Docs/} and roadmapped M0--M12, not yet in C++.

\subsection{UI / audio / VFX (from \texttt{Docs/04,05})}
53 screens (UMG + CommonUI), parchment/brass style, KB+pad+touch day one. Audio Modulation buses (Music/Ambience/World/Ship/Weapons/Foley/UI/Voice), 3--5 variants + pitch, pooled. Niagara VFX via single manager \texttt{VFX.play(name,pos)}, 3 LOD tiers, no blood (slash arcs, hit stars, bone bursts).

\section{How to reproduce / validate}
\label{sec:repro}

\begin{enumerate}[leftmargin=1.4em]
  \item Open \texttt{Brinewake2.uproject} in UE 5.8.3; startup map \texttt{/Game/FirstPerson/Lvl\_FirstPerson}.
  \item Play \texttt{Lvl\_Shooter}: fire at physics props --- expect block, $25$-dmg on NPCs, $100$-unit nudge, $5$\,s corpse linger.
  \item Play \texttt{Lvl\_Horror}: sprint $3$\,s at $600$\,cm/s, confirm $150$\,cm/s recovery penalty + HUD meter events.
  \item Ship milestone (M1): 2 clients + storm, \texttt{p.netshowcorrections 1} clean, no deck jitter.
  \item Collisions: bullets must pass through Trigger volumes (response Ignore) and be blocked by world/pawns.
\end{enumerate}
